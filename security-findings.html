Broken Object-Level Authorization

Access control · IDOR / BOLA

A fictional account can read another account's note when the code omits an ownership check.

Fix: Validate ownership before returning the object; use trusted authentication context in real systems.

Unsafe HTML Rendering

Input handling · XSS prevention

Untrusted fictional markup is inserted into HTML without escaping; the lab does not execute browser scripts.

Fix: Encode text in its correct output context, or use safe DOM text APIs.

SQL Injection
